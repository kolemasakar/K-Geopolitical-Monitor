## Strategic options

### Option A — Continue source expansion only

Advantages:

- directly attacks the largest measured coverage deficit;
- reuses P20.5/P21.4 contracts;
- low architectural novelty.

Limitations:

- does not solve the missing semantic-impact observation by itself;
- risks increasing source count without learning enough about verification/contradiction value.

### Option B — Activate owner-operational pilot only

Advantages:

- produces real semantic and operator evidence;
- exercises Phase 14/15/16/19 capabilities;
- can measure verification, contradiction and forecast-input effects.

Limitations:

- current source universe is too sparse for broad geopolitical usefulness;
- may generate a corpus whose main limitation is already-known missing coverage.

### Option C — Bounded dual-track operational evidence pilot + high-priority coverage expansion

Advantages:

- attacks both first-order constraints;
- creates real corpus evidence while expanding only the highest-priority required cells;
- allows source additions to be evaluated by downstream intelligence contribution, not raw source count;
- reuses validated Phase 13-16 and Phase 19-21 machinery;
- requires no replatforming, public publication or shared runtime.

Risks:

- needs two explicit owner gates: owner-operational activation and the next source-expansion wave;
- operational snapshots must not be mistaken for production/live guarantees;
- source maintenance load increases.

## Audit recommendation

Recommend **Option C** as the next strategic direction.

The next block should be an owner-local, bounded operational-evidence generation and high-priority coverage-expansion block.

It should not be approved merely as “add more sources.” Its success condition should require observed downstream utility:

`SOURCE EXPANSION -> SEMANTIC CORPUS -> P13 VERIFICATION -> CONTRADICTION / ANALYSIS / FORECAST INPUT OBSERVATION -> OWNER UTILITY EVIDENCE`
