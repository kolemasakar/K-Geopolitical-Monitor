# TEST_PLAN

Defines validation requirements for K-Geopolitical Monitor.

Version: 1.0
Status: APPROVED

## Validation Principle

Implementation does not equal validation.

## Minimal Core Tests

The system must validate:

- discovery;
- provenance;
- normalization;
- entity resolution;
- deduplication;
- event versioning;
- verification;
- contradiction handling;
- storyline linking;
- importance scoring;
- forecasting;
- report generation.

## Forecast Evaluation

Forecasts must be compared with later outcomes and used for calibration.
