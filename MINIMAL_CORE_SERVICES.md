## Service boundaries

Minimal Core services:

- ingestion service;
- normalization service;
- entity service;
- event service;
- verification service;
- analysis service;
- forecasting service;
- reporting service.

## Boundary rule

Each service has a clear responsibility and data contract.

Internal implementation may evolve without changing external contracts.
