# MINIMAL_CORE_TEST_CASES
Validation scenarios for Minimal Functional Core.

Version: 0.1
Status: APPROVED

## Test Case 1
New significant event discovered.

Expected:
- source provenance stored;
- event created;
- importance calculated.

## Test Case 2
Multiple sources describe one event.

Expected:
- duplicate publications identified;
- independent evidence preserved.

## Test Case 3
Sources disagree.

Expected:
- contradiction preserved;
- no artificial consensus created.

## Test Case 4
New evidence changes assessment.

Expected:
- event updated;
- forecast recalculated.

## Test Case 5
User provides non-public information.

Expected:
- reliability requested;
- origin preserved;
- verification separated.
