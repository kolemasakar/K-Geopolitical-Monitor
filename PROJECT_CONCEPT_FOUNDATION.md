# PROJECT_CONCEPT_FOUNDATION
Документ фіксує затверджені концептуальні рішення продукту K-Geopolitical Monitor.

Version: 1.0
Status: APPROVED

## Purpose

K-Geopolitical Monitor is a system for discovery, consolidation, verification, analysis and forecasting of significant geopolitical developments.

## Core Principle

The system is not a news aggregator. It builds an evolving geopolitical picture:

Discovery -> Verification -> Analysis -> Relationships -> Forecasting -> Reports

## Scope

The system covers developments affecting:
- international security;
- diplomacy;
- military balance;
- alliances;
- sanctions;
- strategic economy;
- technology balance;
- international order.

## Key Decisions

- Separate repository from K-Research & Critic.
- Minimal Functional Core before global expansion.
- Multi-source verification.
- Support for user-provided non-public information with reliability assessment.
- Forecasting with multiple time horizons.
- Adaptive learning and environment drift detection.

## Forecast Horizons

- SHORT-TERM: up to 1 month
- MEDIUM-TERM: up to 2 years
- LONG-TERM: up to 20 years
- GLOBAL_EVOLUTIONARY: over 20 years
