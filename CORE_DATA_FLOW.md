# CORE_DATA_FLOW

Version: 0.1
Status: ACTIVE

## Data Flow

```text
Source
  |
Raw Item
  |
Claim
  |
Event
  |
Evidence
  |
Verification
  |
Importance
  |
Storyline
  |
Forecast
  |
Report
```

## Requirements

Every analytical conclusion must preserve traceability to underlying evidence.

The system must distinguish:

- observed information;
- verified facts;
- analytical assessment;
- forecast scenarios.

## Event Updates

New information must update event state without destroying previous versions.
