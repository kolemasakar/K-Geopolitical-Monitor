# COVERAGE_CONTRACT

Defines operational monitoring coverage requirements for K-Geopolitical Monitor.

Version: 1.0
Status: APPROVED

## Purpose

The Coverage Contract defines what the system attempts to monitor and how coverage limitations are reported.

## Coverage Dimensions

- time_window
- regions
- countries
- actors
- storylines
- event_categories
- source_classes
- languages
- importance_threshold
- freshness_requirement
- verification_requirement
- cross_check_requirement
- forecast_requirement
- report_depth

## Coverage Principle

Coverage is not measured by the number of sources.

The system must report:

- achieved coverage;
- coverage confidence;
- coverage gaps;
- unavailable sources;
- language or platform limitations.

## Minimal Core

Initial implementation uses limited coverage to validate the processing pipeline before expansion.
